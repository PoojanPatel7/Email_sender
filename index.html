SMTP Setup Guide

1. SMTP Host

Leave this exactly as smtp.gmail.com (assuming you use Gmail). This tells the app which server to connect to.

2. Sender Email

Type your actual Gmail address here (e.g., you@gmail.com). This is the exact address your clients will see the email coming from.

3. App Password (Most Important Step)

Because of Google's strict security, you cannot use your normal Gmail password. You must generate a special 16-letter "App Password" just for this tool.

  1. Turn on 2-Step Verification: Google requires this. Go to your Google Account Security settings and enable it.
  2. Go to App Passwords: Click this direct link to go to the Google App Passwords page.
  3. Create Password: It will ask for an "App name". Type Email Sender and click Create.
  4. Copy Code: Google will pop up a yellow box with a 16-letter password (it looks like abcd efgh ijkl mnop).
  5. Paste in App: Copy that code and paste it into the App Password box in this app!
